# Disease Trend Analysis Dashboard

A Streamlit dashboard for simulating and visualizing disease outbreak trends, predictions, and geospatial data.

## Features

- Time-series case trend and prediction using Linear Regression
- Geospatial hotspot visualization using Folium
- Disease insights and summaries by region and disease type
- Alerts for predicted case thresholds

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
